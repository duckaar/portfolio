## Аналіз процесу підтвердження замовлень та доставки (SQL + Power BI)

📄 Файли проєкту  
https://github.com/duckaar/portfolio/tree/main/SQL/Brazilian_e_commerce

У цьому проєкті було проаналізовано процес обробки замовлень у e-commerce датасеті Olist (Brazilian E-commerce dataset).

Що було зроблено:

- аналіз часу підтвердження замовлень у різних штатах
- виявлення аномально довгих випадків підтвердження
- дослідження зв’язку між відстанню між продавцем і покупцем та часом доставки
- розрахунок відстані між точками за формулою Haversine
- візуалізація результатів у Power BI

Основні висновки:

- середній час підтвердження замовлення у більшості штатів становить 9–12 годин
- окремі аномальні випадки можуть перевищувати 200 годин
- на рівні окремих замовлень кореляція між відстанню та часом доставки слабка
- після агрегування за діапазонами відстані видно логічну тенденцію: зі збільшенням відстані зростає середній час доставки
