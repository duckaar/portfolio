# Аналіз продажів E-Commerce (SQL + Power BI)

## Опис проєкту

У цьому проєкті представлений повний цикл аналізу даних інтернет-магазину з використанням **PostgreSQL** для обробки та розрахунку метрик і **Power BI** для візуалізації результатів.

Метою проєкту є демонстрація практичних навичок роботи з SQL у бізнес-контексті через аналіз продажів, поведінки клієнтів та структури товарів.

Аналіз охоплює:

* Розрахунок ключових бізнес-метрик (KPI)
* Аналіз структури статусів замовлень
* Динаміку виручки у часі
* Концентрацію виручки за категоріями та товарами (Pareto-аналіз)
* Аналіз поведінки клієнтів (нові vs повторні, когортна логіка)

---

## Використані інструменти

* **PostgreSQL** — аналіз даних та розрахунок метрик
* **DBeaver** — робота з базою даних
* **Power BI** — побудова дашбордів та візуалізація

---

## Основні задачі

* Розрахувати та структуризувати ключові бізнес-метрики
* Проаналізувати тренди продажів у часі
* Виявити топ-категорії та продукти
* Оцінити рівень концентрації виручки
* Проаналізувати клієнтську поведінку та повернення

---

## Продемонстровані SQL-навички

* Агрегації (`SUM`, `COUNT`, `COUNT DISTINCT`)
* Window-функції (`LAG`, `RANK`, накопичувальний `SUM`)
* `PARTITION BY`
* CTE (`WITH`)
* Робота з датами (`DATE_TRUNC`)
* Умовна агрегація (`FILTER`)
* Self-join
* Обчислення часток та безпечне ділення (`NULLIF`)
